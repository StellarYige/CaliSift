## 已复现并修复

| 问题 | 证据与结果 |
| --- | --- |
| 姓名在行或列中、前面还有其他人时，时间文本被误读成日期轴 | 合成矩阵用例复现日期丢失和时间冲突；修复后只关联目标姓名及其日期，不取另一人的班次作表头 |
| 既有 `合并表头.xlsx` 漏掉同轴的班次子表头 | 原结果标题为“合并表头”；现在得到对应的“早班”“晚班”，保留单元格证据 |
| “晚上十点至次日六点”继承“晚上”成为次日 18:00 | 现在为 22:00 至次日 06:00；共享小时后缀的 `8-16时` 也按区间解析 |
| 独立结束列的次日标记、24:00、Excel 完整时间戳丢失日期信息 | 覆盖次日同一时刻、次日更晚时刻、午夜及跨年结束日期；日期证据矛盾或超出当前单次跨夜范围的区间保留待确认 |
| 多个带空格的日期仅取第一个；缺开始时间或明确“待定”被视为确定 | 多日期保留待确认；不识别的起止列和只有结束时间标为待确认；取整到 24:00 的 Excel 小数时间不输出非法时钟值 |
| 修正草稿后冲突未刷新 | 每次修正重算冲突；明确“已核对”后的原警告保存在修正历史，原文证据不改写 |
| 核对列表漏显已确定但冲突或信息不完整的项 | 增加分类数量、筛选、优先排序、实际结束日期、缺失信息说明和冲突项原文按钮；筛选批量勾选保留范围外的选择 |
| 新导入项与本机已有安排的冲突在提交前不可见 | 变化预览显示涉及本次新增或修改项的冲突及双方原文摘录；仅预览不会写入日历 |
| 同名文件可能定位错误、宽表只跳姓名页、迟到的分页响应覆盖当前文件 | 按内容身份定位；默认跳安排/时间单元格，支持逐字段跳转；拒绝迟到的旧响应；旧任务若无法唯一定位则展示摘录和明确提示 |
| 导入保存清理暂存文件后，迟到的原文读取错误弹到导出页 | 原生截图复现、桥接跟踪确认错误来自 `table`；过期读取的成功和失败响应均隔离，当前请求失败仍提示；原生脚本增加最终无错误提示断言 |
| 待确认且无日期的修正表单可能抛出无效日期异常 | 可以保留待确认草稿；跨夜结束时间给出就地提示 |
| ICS 更新含义不够明确、异步旧预览可能恢复 | 导出页和保存按钮旁均说明“安排快照”，不保证重导入更新或删除；方案变化后忽略旧预览响应 |

最初新增的 19 个解析边界断言中，原实现出现 **18 失败、1 通过**；另在直接读取既有合并表头样本时定位到上述标题问题。修复后的结论以最终测试结果为准，不将所有新增断言都说成原先失败。
