## 执行结果

- `scripts/test.ps1`：**193 项 Python 测试、25 项前端测试全部通过**，无跳过；Python 总覆盖率 **93.33%**，保持原 90% 门槛。完整运行约 40 秒。
- 实际页面方法 + 真实 HTTP 的 `npm run smoke` 已通过：四表得到 5 项安排、1 组冲突；确认前无保存；确认后保存；修正后冲突消除；重新启动从 v2 本机文件恢复；旧报告修正接口仍可使用。
- 本地真实 HTTP `/api/ocr` 返回 200，清晰样图得到 1 项正确安排、1 份局部图片证据；`/health` 返回 `version: 0.2.0`、Excel 可用、OCR 就绪。Python HTTP 核验显式禁用环境代理，避免本地地址被代理接管。
- 官方编译器成功编译 7 个 WXML 页面和 8 个 WXSS 文件，生成 15 种静态状态。
- 已检查 390px 时间线和 320px 大字号日常视图静态截图，位于 `artifacts`。静态浏览器最小视口与截图宽度不同，因此固定宽度预览显式按 320 / 390px 换算 rpx。它们是编译产物视觉检查，不是微信原生控件测试。
- 本机 CPU 上，5000 条不同日期安排的追加约 1.96 秒；再次追加同样内容约 2.52 秒，保持 5000 条安排、报告 5000 项重复。该测量是本机 Python 核心，不能代表手机渲染性能。

## OCR 真实模型回归

所有 OCR 正向集成测试调用已安装的真实模型；模拟仅用于缺模型 / 超时 / HTTP 失败等控制路径。开发中发现 RapidOCR 会尝试下载可视化字体，已将字体固定并放到安装阶段；测试时阻断网络，确认推理不依赖运行时下载。

当前回归清单为 `tests/fixtures/ocr/regression-manifest.json`。六张正向图片分别是清晰、旋转、轻度倾斜、压缩、合并标题、无边框版本；它们来自**同一个人工绘制明细表布局**。另有模糊和不确定线框用于限制 / 失败路径测试。

本次六张正向回归样本的结果：

| 指标 | 实测 |
| --- | --- |
| 姓名错误关联 | 0 / 6 |
| 草稿提取精确率 / 召回率 | 6/6 / 6/6 |
| 日期 / 时间字段正确 | 6/6 / 6/6 |
| 待确认 | 0 / 6 |
| 手动修正操作量 | 未做独立用户操作计量，不填为 0 |
| 独立布局数 | 1 |

这些数字只说明此回归集通过，**不能外推成真实照片 98% / 95% 达标**。评测器实际输出 `acceptance_passed: false`，原因包括不足 20 种独立表格布局、不足 20 张验收图片、含合成样本、缺少独立人工复核与操作量记录。输出见 `artifacts/accuracy-regression.json`。

接受真实脱敏或公开样例后，可参照回归清单填写实际文件、姓名、年份、独立布局分类、姓名单元格和人工预期结果，运行：

```powershell
.\.venv\Scripts\python.exe -m scripts.evaluate_accuracy path/to/manifest.json --acceptance --output artifacts/acceptance.json
```

同一模板变体不得填写不同布局编号来抬高数量。解析代码覆盖率不作为识别准确率。

## 未完成的验收与限制

1. 缺少独立于开发样例的 20 种布局和 20 张真实照片 / 截图验收集；不能用现有六个合成变体替代。工作 / 学习综合准确率和人工操作量尚未给出发布结论。
2. 保留并使用项目现有 AppID 启动了微信开发者工具自动化，CLI 返回成功，自动化可连接并读取当前页面路径，但页面数据、截图 / 页面操作未能完成，70 秒后看门狗终止。原生微信文件选择、图片选择、页面跳转、本机恢复尚未完成本轮真机验收。
3. 当前会话的内置浏览器没有可用连接；静态视觉检查使用独立 headless Chrome 和官方编译产物。开发者工具窗口捕获为空白，未将其当成有效界面截图。
4. iOS、Android 及其他手机日历均未做本轮真实 ICS 导入、重复导入、更新、取消和提醒验证。界面明确静态导出，不显示同步成功或微信提醒开启。
5. 裁剪目前使用旋转后图片的百分比边界输入；可工作，但尚未做触摸拖拽式裁剪体验。复杂表格模板的交互仅覆盖前 20 行 / 15 列的局部表头。
6. 课程展开采用明确的课程配置；未实现任意学校周期课表自动转课程定义。无法解析的周期课表继续保留待确认证据。
7. 5000 条容量目前按所有保留记录计数，隐藏和取消记录也计入；清理入口清除当前日历，尚无按历史日期区间归档界面。大型导入草稿 / 变化预览采用每页 50 项；手机端最大容量实测未完成。

无需部署数据库或云端任务即可使用当前本地功能。发布前仍需完成以上独立数据和设备验收，必要时继续收窄公开支持范围。
