# CaliSift 0.3.0-alpha.1

星程的首个开源桌面开发预览：在自己的 Windows 电脑上提取、核对和积累个人安排，再导出 ICS。不需要微信、云服务器、账号或大模型密钥。

## 文件

- `CaliSift-0.3.0-alpha.1-windows-x64-setup.exe`：Windows 11 x64 完整安装包，包含 Python、OCR、固定模型、字体和 WebView2 离线安装程序。
- `CaliSift-models-ppocrv5-v1.zip`：设置页可选择的离线模型修复包。
- `CaliSift-third-party-source-0.3.0-alpha.1.zip`：随包依赖的对应源码和构建说明；安装目录内也保留一份。
- `CaliSift-0.3.0-alpha.1-source.zip`：本次源码快照，不含个人数据、模型或开发环境。
- `SHA256SUMS.txt`：以上资产的 SHA-256 校验值。

安装包当前**未签名**，以本次发布的校验值核对下载内容。随包微软运行时与构建工具的发布者签名已校验；这不等同于 CaliSift 安装包已签名。不要求关闭系统保护。

## 开始使用

安装后选择“先用示例体验”，依次识别、预览、确认保存、导出 ICS。自己的文件可以选择或拖入；姓名必须与原文一致。日程只有在确认后才保存，更新旧来源必须核对覆盖日期和对应关系。

默认数据目录为 `%LOCALAPPDATA%\CaliSift`。更新安装前自动建立恢复点，卸载保留数据。便携备份可以在设置中导出，恢复默认建立独立工作区。

## 本次范围

已验证本机真实表格解析、真实 ONNX OCR、原生文件对话框、持久保存、ICS 写出及重启恢复；自动回归涵盖过期预览、来源更新、个人修正、备份、模型故障和导出修订。详细结果和复现脚本见[桌面验收记录](verification-alpha1.md)。

238 项 Python 测试通过，覆盖率 91.95%；6 项桌面交互和 25 项历史迁移测试通过。当前 Windows 机器上的安装、升级恢复点、便携备份恢复和卸载保留数据已通过原生验证。

本版本面向清晰打印体和简单布局。独立 20 布局 / 20 图片验收、无 WebView2 的干净机器以及外部桌面 / iOS / Android 日历导入尚未完成；不宣称图片准确率目标已经达到，也不宣称静态 ICS 可以自动同步或删除外部旧安排。
